# 腕・脚 疑似3D挙動統一

## 目的
足で自然に見えていた自由ポーズ処理を腕にも適用し、腕専用の補正・更新処理を廃止しました。

## 共通モデル
各部材は `{x, y, z}` の局所ベクトルを持ちます。

- 正面: `{x, z}` を表示・編集
- 側面: `{y, z}` を表示・編集
- 正面編集では `y` を保持
- 側面編集では `x` を保持
- `z` は両ビューで共有

上腕 → 肘 → 前腕 → 手、太もも → 膝 → すね → 足、の親子関係は従来どおりです。

## 廃止した腕専用処理
- `isArmHandle()` による更新分岐
- `seededArmSpatial()`
- `armPlanarVector()`
- `projectedHorizontalFromSpatial()` による腕専用表示補正

## マウス操作改善
部材が奥行き方向を向き、画面上で親子関節がほぼ一点になった場合に、表示上の長さをそのまま操作半径にするとドラッグ不能になります。

そこで、投影長が 6px 未満の場合のみ:
1. pointerdown では座標を変更しない
2. 5px 以上ドラッグして方向が決まるまで待つ
3. 既定の部材長を操作半径として復元する

通常状態では従来どおり現在の投影長を使用するため、足の良好な挙動を変えすぎないようにしています。
