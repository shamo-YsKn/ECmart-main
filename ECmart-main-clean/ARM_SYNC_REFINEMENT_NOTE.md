# Arm sync refinement

足の挙動と腕の挙動を比較し、腕側だけを修正しました。

## 原因
- 脚は側面の前後成分が小さく、XZ/YZのZ共有だけでも自然に見えやすい。
- 腕は側面の前後成分が大きく、さらに正面で真横にすると側面投影が点に近くなる。
- 旧処理は「現在見えている投影長」を次のドラッグ半径に使っていたため、側面で点に近づいた腕を再操作すると挙動が不安定になりやすかった。
- 側面の肩アンカーが正面より12〜19px低く、共有Zでも絶対高さが揃わなかった。

## 修正
- 腕だけ、正面はXZ・側面はYZの固定操作長を使用。
  - 正面: 上腕/前腕 40px
  - 側面: 上腕45px / 前腕47px
- 正面編集ではYを保持、側面編集ではXを保持、Zだけ共有。
- 初めて腕を空間化するときは、正面姿勢をそのままX/Zへ使い、Y=0を初期値にする。
  - 正面で腕を真横にすると、側面では点に近い投影になる。
  - 正面で腕を上げると、側面では同じ高さZへ連動する。
- 側面の肩高さを正面と同じ y=104 に統一。
- 脚の計算は変更なし。

## マウス操作
- Pointer Capture を小さい関節ハンドルではなくSVG編集面全体へ移動。
- ドラッグ中にハンドルがカーソルからずれても追跡しやすくした。
