# スマホ版アイテム工作対応

## 概要
スマホでも2Dアイテム工作を行えるように、既存の工作ロジックを維持したままタッチ向けUIとモバイル認証ブリッジを追加しました。

## スマホで利用できる機能
- 基本パーツの追加
- ガチャで獲得済みの特殊工作素材の追加
- 指ドラッグによるパーツ移動
- 接続点スナップ ON/OFF
- 正面 / 側面 / 背面の3方向編集
- パーツ回転
- パーツ拡大縮小
- 手前 / 奥へのレイヤー移動
- 複製 / 削除 / 接続解除
- 参考価格スコア表示
- アカウントへの保存 / 上書き / 別作品保存
- スマホのマイページから保存済みアイテムを再編集
- 保存済みアイテムをロボットへ持たせる
- AI/ルールベース提案の工作案をスマホ工作台へ直接読み込み

## スマホ向けUI
PC版の3カラムをそのまま縮めるのではなく、スマホでは以下の順に操作します。

1. 工作台
2. 「パーツ追加」「選択パーツ調整」の切替ボタン
3. 選択したパネル
4. 作品名・保存操作

パーツのSVGタッチ領域も拡大し、指で掴みやすくしています。

## 認証・保存
スマホ互換サイトのログインはHttpOnly Cookieを利用しているため、React工作台から直接ブラウザ側Supabaseセッションを要求しません。

追加API:
- `GET /api/mobile/workbench-context`
  - ログイン状態
  - custom_items保存可否
  - ガチャ解放素材ID
- `POST /api/mobile/custom-item`
  - HttpOnly Cookieのログイン情報を使って自作アイテムを保存
- `POST /api/mobile/workbench-draft`
  - AI提案や保存済みアイテムをsessionStorageへ安全に受け渡して工作台を起動

## React互換フォールバック
`pose` と `workbench` はタッチドラッグのため通常時のみReact版を起動します。
React hydrationが失敗して `?compat=1` に切り替わった場合は、サーバー互換画面へ退避し、編集画面の再試行リンクを表示します。

## DB変更
追加SQLやDB migrationはありません。既存の `custom_items` とガチャ在庫を利用します。
