# まち歩き：向き切替 + 室工大第2壁画ステージ

## 1. 壁画ロボットの向き
- 投稿時に **正面 / 側面 / 背面** を選択できます。
- 投稿データに `robot_view` を保存します。
- 壁画上、レビュー一覧、レビュー詳細、作者投稿一覧で保存した向きを再現します。
- 既存投稿は `front` として扱います。

## 2. 室工大の第2壁画
- 地図上の室工大ピンは1つのままです。
- 室工大を開くと、以下の壁画ステージを切り替えられます。
  - キャンパス
  - 研究エリア
- 研究エリアは **ロボット / 建築 / 化学** を中心に構成しています。
- ロボットアーム、構造物、研究棟、フラスコ等のモチーフを追加しています。
- ステージごとに投稿を分けるため `mural_variant` を保存します。

## 3. NPC
- 街のボルタ・ナッティにも正面だけでなく側面・背面が混ざるようにしました。
- 室工大の2つの壁画では日替わりseedも分けています。

## 4. スマホ版
- 室工大のキャンパス / 研究エリア切替を閲覧できます。
- 投稿ロボットは保存された正面 / 側面 / 背面で表示します。
- 投稿編集自体はこれまでどおりPC版中心です。
