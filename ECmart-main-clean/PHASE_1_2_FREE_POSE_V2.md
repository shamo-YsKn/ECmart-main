# Phase 1-2 v2: 3方向対応 2D自由ポージング

## 今回の修正

ユーザーからのフィードバックを基に、Phase 1-2を改良しました。

1. 足先のY座標固定を撤廃
   - 片足を上げる
   - 大股に開く
   - ひざを深く曲げる
   - 脚を前後に出す
   といったポーズを作りやすくしました。

2. 編集キャンバスを縦方向へ拡張
   - SVG viewBoxを `0 0 300 320` とし、脚の可動余白を増やしました。

3. 正面 / 側面 / 背面すべてで自由ポーズ編集
   - 正面: 左右方向の関節角を編集
   - 側面: 前後方向の関節角を編集
   - 背面: 正面と同じ物理ポーズを後ろから鏡像表示して編集

4. 側面を専用デザインへ変更
   - 共有されたPowerPointイメージを参考に頭部を側面プロファイル化
   - 腕・脚を奥側/手前側の2本ずつ表示
   - 奥側は少し薄く、胴体の後ろへ配置
   - ナッティの皿ねじスカートを側面専用の台形形状へ変更

5. 背面を専用デザインへ変更
   - 正面の「目」は表示せず、六角ボルト頭の裏面として表現
   - 正面ポーズとの整合を保ったまま後ろから編集可能

## 2.5D関節データ

`RobotPoseState` は以下の考え方です。

- `axes.front`: 正面/背面で共用
- `axes.side`: 側面で編集する前後方向
- `joints`: Phase 1-2 v1互換のfront軸

旧ロボットは `poseState` がなくてもプリセットとして読み込めます。
Phase 1-2 v1の `joints` のみを持つデータも `axes.front` へ自動的に引き継ぎます。

## 現時点の3D

3D自由ポーズはPhase 7でIK対応する予定のため、自由ポーズ編集中は2D編集を使用します。既存3Dプリセット表示は維持しています。

## スマホ互換モード

スマホUser-Agent向けのサーバー互換表示は、React hydrationに依存しない安定経路を維持するため、現時点ではプリセット編集を維持しています。Reactクライアント工房ではpointer操作のためマウス/タッチの両方に対応する実装です。
