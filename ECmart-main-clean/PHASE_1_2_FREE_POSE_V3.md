# Phase 1-2 v3: 頭部分離・頭/目の向き調整

Phase 1-2 v2へのフィードバックを反映した更新です。

## 変更点

1. 側面の頭部
   - ボルト頭本体と、目になっているねじを別SVG部品として描画
   - 目ねじは短い軸＋ねじ頭の側面プロファイルで表現
   - 奥側の目ねじも薄く表示して立体感を追加

2. 背面の頭部
   - ボルト頭本体と目ねじの裏側を別部品化
   - 正面の＋溝は背面には表示せず、ねじ頭の裏側として表現

3. 頭・目の向き
   - `headPose.yaw`: 頭の左右 ±30°
   - `headPose.pitch`: 頭の上下 ±15°
   - `headPose.eyeYaw`: 目ねじの左右 ±15°
   - `headPose.eyePitch`: 目ねじの上下 ±8°
   - 工房の「見た目を調整」から4本のスライダーで設定

4. 3D表示
   - 頭のyaw/pitchを3Dの六角ボルト頭グループにも反映
   - eyeYaw/eyePitchを3Dの2本の目ねじにも反映

5. 保存互換
   - `RobotConfig.headPose` をoptionalで追加
   - 旧保存データは `{ yaw:0, pitch:0, eyeYaw:0, eyePitch:0 }` として自動補完
   - SupabaseはJSONの `saved_robots.config` 内に保存するため追加SQL不要

## 補足

2Dの頭向きは立体モデルを2Dに投影した簡易表現です。正面・側面・背面で同じ `headPose` を使うため、今後の3D自由ポーズやジオラマにも流用できます。
