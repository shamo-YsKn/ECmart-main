# Phase 4: マイジオラマエディタ 初版

## 実装内容

- ガチャで獲得した室蘭背景 + スターター「ボルタ工房」から背景選択
- 保存済みボルタ / ナッティを複数配置
- 自作アイテムを複数配置
- ドラッグ移動、回転、拡大縮小、前後順、複製、削除
- ジオラマ名を付けてSupabaseへ保存
- マイページでプレビュー、再編集、削除
- 使用中ロボット / 自作アイテムの削除ガード

## 保存データ

既存の `DioramaDocument` / `SceneTransform` を使用します。

- 座標系: `diorama-stage-v1`
- 2Dステージ: 640×360相当のローカル座標
- X/Y: 配置位置
- Z: 重なり順
- rotationDeg.z: 回転
- scale: 均一スケール

同じ `savedRobotId` / `customItemId` を複数の `placementId` で配置できます。

## Supabase

`supabase/dioramas-migration.sql` を1回実行してください。

既存の購入、ガチャ、ロボット、自作アイテムのテーブル変更はありません。

## 現段階の制限

- ジオラマは2D/2.5D
- ジオラマ内でロボットのポーズそのものを再編集する機能は未実装
- 公開 / いいね / ギャラリーはPhase 6
- スマホサーバー互換モードでは自由ドラッグ編集を提供せず、PC Reactクライアント版を中心に利用
