# Phase 5: 室蘭マップ・スポット別壁画

## コンセプト変更

従来の「1枚の巨大な壁画」ではなく、室蘭の小さなデフォルメマップから場所を選び、その場所の情報・場所限定壁画・レビューを一体で見る方式に変更しました。

## 実装済み

- 室蘭デフォルメマップ
- 店舗 / 観光地 / 室蘭工業大学 / 港 / 工場夜景 / 工房のスポット
- スポットごとの専用SVG壁画背景
- 保存済みボルタ / ナッティを壁画へ投稿
- 投稿位置、大きさ、傾きの調整
- レビュー詳細表示
- 新着 / 人気レビュー
- いいね
- 投稿者の公開壁画投稿一覧
- 店舗スポットでEC商品を表示しカート追加
- 投稿不足時の「街のボルタ / ナッティ」自動生成

## NPCルール

NPCは実レビューと誤認されないよう「街のロボット / 自動生成」と明示します。

- `spotId + YYYY-MM-DD` を乱数seedに使用
- 同じ日は同じ顔ぶれ・配置
- スポット別に色 / ポーズ / アイテム / ボルタとナッティの比率を設定
- 実投稿が増えるほどNPC数を減らす
- 実投稿が十分多い場合も最低2体だけ街の住人として残す
- NPCはレビュー / 作者 / いいねを持たない

## Supabase

`supabase/mural-community-migration.sql` を1回実行します。

追加テーブル:

- `mural_posts`
- `mural_post_likes`

壁画閲覧といいね件数は公開。いいねの生データは本人だけ閲覧でき、公開画面には集計RPCで件数だけ返します。投稿・削除・いいね追加/解除は認証ユーザー本人だけにRLSで制限します。

## 投稿スナップショット

壁画投稿はレビュー当時の見た目を維持するため、投稿時の `RobotConfig` と、必要なら `CustomItemDocument` をスナップショット保存します。

元の保存ロボットを後から編集しても、過去レビューの見た目は勝手に変化しません。

## スマホ互換モード

スマホサーバー表示では以下を閲覧可能です。

- スポット選択
- スポット情報
- 街のロボット
- 公開レビュー
- 店舗の商品

自由配置投稿・いいね・作者詳細はPC React版を中心に提供します。
