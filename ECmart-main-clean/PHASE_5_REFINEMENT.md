# Phase 5 refinement: pose studio + grounding

## 今回の修正

### 自由ポーズ専用画面
- ロボット工房から `自由ポーズ専用画面` へ遷移する方式に変更。
- 正面と側面を同時表示。
- 正面は左右軸、側面は前後軸を編集。
- 操作中の関節を反対ビューへオレンジの投影点として表示。
- 背面は確認用プレビューとして表示。
- 保存形式は既存 `poseState.axes.front / side` のままなのでSupabase migration不要。

### ロボット表示
- 腕先の皿ねじを腕の最終線分へほぼ直交する向きで追従させる。
- 側面: 六角ボルト頭の側面と目ねじの頭・短い軸を別部品として再配置。
- 背面: 目ねじを大きな円として見せず、頭部の前面へ差し込まれた軸/カラーが上端から少し見える構造へ変更。
- 頭/目の向きUI自体は今回変更していない。次回、図をもとに再設計予定。

### マイジオラマ
- 新規配置できるロボットは最大5体。
- 既存データ互換のため保存モデル上の旧上限24体は維持。
- ロボットはドラッグ時に地面またはステージごとの足場へ自動接地。
- 室蘭工業大学の屋上、白鳥大橋デッキ、港の岸壁、工場屋上など一部背景に足場を設定。
- ステージ切替時も既存ロボットを新背景の足場へ再接地。

### スポット別壁画
- 壁画上のロボット総数を約5体に制限。
- 新着ユーザー投稿を優先し、不足分だけ街のボルタ/ナッティで補完。
- 実投稿が5体以上ならNPCは0体。
- 全レビューは下部レビュー一覧に残る。
- 壁画上のロボットは基本的に画面下部の地面へ接地。
- 大学校舎、白鳥大橋、工場建物など明確な足場付近をクリックした場合は足場へ吸着。

## DB

追加SQLは不要。既存の `saved_robots.config`, `dioramas.document`, `mural_posts` をそのまま利用する。
