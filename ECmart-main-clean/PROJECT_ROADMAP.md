このファイルは、会話が新しいチャットへ移った場合でも開発方針を復元できるようにするための引き継ぎ資料です。

## 現在の基準版

現在のサイトには、以下が実装済みです。

- 室蘭の店舗・商品を中心にしたECデモ
- カート、購入確認、購入完了
- 購入額に応じたポイント付与

実決済は未接続です。購入処理はサイト内のデモ注文・ポイント処理のみです。

## 開発原則

1. 既存の `saved_robots.config` 形式を急に破壊しない。
2. PC版とスマホ版で同じ設定値・解放条件・正規化処理を使う。
3. 座標、回転、拡大率、関節角、所持品参照を将来機能で使い回せる形にする。
4. 永続化データにはバージョンを持たせ、将来の形式変更を移行可能にする。
5. 画面pxそのものを永続化の基準にしない。各エディタのローカル座標系を使う。
6. 回転角は保存時に degree へ統一し、描画側で必要に応じて変換する。
7. ガチャや購入などポイントが動く処理はサーバー側で確定し、再送時の二重処理を防ぐ。
8. まず2D/2.5Dで制作体験を完成させ、3D高度化は後段で行う。

## Phase 1: 制作基盤

### 1-1. 共通データ設計【今回実施】

`lib/creation-model.ts` を共通契約とする。

- `SceneTransform`
  - position
  - rotationDeg
  - scale
- `RobotPoseState`
  - preset / custom
  - 関節角
- `RobotCreationDocument`
- `CustomItemDocument`
- `DioramaDocument`

既存 `RobotConfig` は当面互換形式として維持する。

### 1-2. 2D自由ポージング【実装済み / v2】

- 肩、ひじ、股関節、ひざをドラッグ操作
- 固定ポーズをプリセットとして維持
- 足先Y固定を廃止し、片足上げ・大股・深いひざ曲げに対応
- 正面 / 側面 / 背面の3方向で自由ポーズ編集
- 正面/背面はfront軸、側面はside軸として2.5D保存
- 背面は正面ポーズを後ろから見た鏡像として編集
- 側面は共有されたPowerPointイメージを基準に、奥側/手前側の腕・脚を2本ずつ描画
- ナッティ側面の皿ねじスカート形状を専用化
- 旧固定ポーズデータとPhase 1-2 v1の `joints` 保存を自動移行

補足: スマホのサーバー互換モードは安定性優先でプリセット編集を維持。自由ドラッグ編集はReactクライアント工房で利用する。

## 機能の循環

最終的な体験は次の流れを目指す。

室蘭の商品を見る・買う（デモ）
→ ポイント獲得
→ ガチャ
→ 色 / 素材 / 背景を獲得
→ ボルタ・ナッティを制作
→ 自由ポーズ
→ 自作アイテム工作
→ ジオラマ制作
→ マイページ展示
→ 壁画広場・ギャラリーへ共有
