## 開発原則

1. 既存の `saved_robots.config` 形式を急に破壊しない。
2. PC版とスマホ版で同じ設定値・解放条件・正規化処理を使う。
3. 座標、回転、拡大率、関節角、所持品参照を将来機能で使い回せる形にする。
4. 永続化データにはバージョンを持たせ、将来の形式変更を移行可能にする。
5. 画面pxそのものを永続化の基準にしない。各エディタのローカル座標系を使う。
6. 回転角は保存時に degree へ統一し、描画側で必要に応じて変換する。
7. ガチャや購入などポイントが動く処理はサーバー側で確定し、再送時の二重処理を防ぐ。
8. まず2D/2.5Dで制作体験を完成させ、3D高度化は後段で行う。

## Phase 1: 制作基盤

### 1-1. 共通データ設計【今回実施】

`lib/creation-model.ts` を共通契約とする。

- `SceneTransform`
  - position
  - rotationDeg
  - scale
- `RobotPoseState`
  - preset / custom
  - 関節角
- `RobotCreationDocument`
- `CustomItemDocument`
- `DioramaDocument`

既存 `RobotConfig` は当面互換形式として維持する。

### 1-2. 2D自由ポージング【実装済み / v2】

- 肩、ひじ、股関節、ひざをドラッグ操作
- 固定ポーズをプリセットとして維持
- 足先Y固定を廃止し、片足上げ・大股・深いひざ曲げに対応
- 正面 / 側面 / 背面の3方向で自由ポーズ編集
- 正面/背面はfront軸、側面はside軸として2.5D保存
- 背面は正面ポーズを後ろから見た鏡像として編集
- 側面は共有されたPowerPointイメージを基準に、奥側/手前側の腕・脚を2本ずつ描画
- ナッティ側面の皿ねじスカート形状を専用化
- 旧固定ポーズデータとPhase 1-2 v1の `joints` 保存を自動移行

補足: スマホのサーバー互換モードは安定性優先でプリセット編集を維持。自由ドラッグ編集はReactクライアント工房で利用する。

## Phase 2: アイテム工作【実装済み】

### 2-1. 2Dアイテム工作エディタ【実装済み】

- 基本工作パーツ11種類
- 配置 / ドラッグ移動 / 回転 / 拡大縮小
- 重なり順 / 複製 / 削除
- 自作アイテムの命名・Supabase保存
- アカウントから一覧表示・再編集・削除

### 2-2. スナップ接続【実装済み】

- 各パーツに接続socketを定義
- 近づけると最寄りsocketへ吸着
- スナップON / OFF
- 接続解除
- `attachedTo` に自分/相手のsocketを保存
- 親パーツの移動に接続済み子パーツが追従
- 回転 / 拡大縮小時に接続位置を再計算

### 2-3. ロボットへの装備【実装済み】

- ロボット工房へ「マイアイテム」を追加
- 自作アイテムを右手へ装備
- 自由ポーズの手位置へ追従
- 大きさ / 回転 / X/Y位置を調整
- `RobotConfig.heldItem` として保存
- 保存済みロボット/アバター2D表示へ反映
- 装備中アイテムの誤削除を防止

基本工作部品は無料で使用可能。特殊素材はPhase 3のガチャ拡張で追加する。
自作アイテムは現時点で2D制作物のため、装備中は3D表示を停止する。

## Phase 5: 室蘭マップ・スポット別壁画【初版実装済み】

従来案の「1枚の巨大な壁画広場」から、室蘭の場所とレビューを直接結びつける方式へ変更。

### 5-1. 室蘭ミニマップ・場所限定壁画【実装済み】

- デフォルメした室蘭ミニマップ
- お店 / 観光地 / 大学 / 港 / 工房をスポット化
- スポットをクリックすると情報と専用壁画を表示
- 場所ごとに異なる壁画デザイン
  - 室蘭工業大学: 校舎 / 鉄 / 歯車 / ロケット
  - 地球岬: 海 / 水平線 / 灯台
  - 白鳥大橋: 海 / 吊橋
  - 測量山: 山 / アンテナ / 夜景
  - 工場夜景: 配管 / 煙突 / 工場の灯り
  - 店舗: 暖簾 / 炭火 / 丼 / 工房など
- 店舗スポットでは既存EC商品を壁画ページ内に表示し、そのままカート追加可能

### 5-2. 壁画レビュー投稿【実装済み】

- 保存済みボルタ / ナッティをレビューアバターとして投稿
- 壁画クリックで投稿位置を選択
- 投稿時に大きさ / 傾きを調整
- 自由ポーズ / 頭向き / 自作アイテム装備をスナップショットとして公開表示
- ロボットをクリックするとレビュー詳細を表示
- 投稿者名、投稿日時、レビューを表示
- ユーザー投稿には吹き出しアイコンを付け、自動生成キャラと区別
- 同じユーザー・同じスポット・同じ保存ロボットの重複投稿を防止

### 5-3. 過疎防止NPC・いいね・作者表示【実装済み】

- 投稿が少ないスポットには「街のボルタ / 街のナッティ」を自動生成
- NPCはレビューを持たず、自動生成であることを明示
- `spotId + 日付` をseedにし、同じ日は同じ顔ぶれ / 配置
- 実投稿が増えるほどNPC数を減らす
- スポットごとに色 / ポーズ / アイテム / ボルタ・ナッティ比率を変更
- ユーザー投稿へのいいね
- 新着 / 人気レビュー切り替え
- 投稿者をクリックすると、その人の公開壁画投稿一覧を表示

Supabase: `mural_posts` / `mural_post_likes` を `supabase/mural-community-migration.sql` で追加。壁画閲覧は公開、投稿 / 削除 / いいねはログインユーザー本人の操作だけ許可する。

スマホ互換モードではスポット選択、NPC、公開レビュー、店舗商品をサーバー表示で閲覧可能。自由な壁画配置投稿・いいね・作者詳細はPC React版を中心に提供する。

## 機能の循環

最終的な体験は次の流れを目指す。

室蘭の商品を見る・買う（デモ）
→ ポイント獲得
→ ガチャ
→ 色 / 素材 / 背景を獲得
→ ボルタ・ナッティを制作
→ 自由ポーズ
→ 自作アイテム工作
→ ジオラマ制作
→ 室蘭マップからスポット別壁画へレビュー投稿
→ マイページ / ギャラリーへ作品共有

## 新しいチャットでの引き継ぎ方法

このプロジェクトZIPを新しいチャットへ渡し、以下のように伝える。

> 「マチノワ室蘭のボルタ・ナッティ開発ロードマップの続きです。PROJECT_ROADMAP.md と docs/CREATION_DATA_MODEL.md を読んで、現在の実装を壊さず次のPhaseを進めてください。」

これを開発の基準とする。
