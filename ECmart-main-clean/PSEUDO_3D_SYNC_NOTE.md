# Pseudo 3D sync note

今回の調整では、2D自由ポーズの正面・側面同期を「同じ数値をそのまま見せる」方式から、
「反対ビューの角度を使って見え方を短縮する」疑似3D表示へ変更しました。

## 変更内容
- `lib/robot-pose-2d.ts`
  - `pseudo3DProjectionScale()` を追加
  - 正面表示では側面角度、側面表示では正面角度を参照して、腕・脚の見かけの長さを補正
- `components/robot/robot-pose-studio.tsx`
  - 説明文を疑似3D同期の内容に更新

## 見え方
- 真下 / 真上: 見かけ長さ = 100%
- 斜め: 見かけ長さ ≒ 75%
- 真横: 見かけ長さ ≒ 14%（点に近い）

これにより、正面で腕を真横に広げたとき、側面では腕が短く見えるようになります。
