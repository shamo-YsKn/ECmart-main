# 購入・ポイント機能

## 動作

1. カートに商品がある場合だけ購入ボタンを表示します。
2. 注文内容、送料、合計、獲得予定ポイントを確認します。
3. 購入確定後、注文と明細をSupabaseへ保存します。
4. 100円ごとに200ptをアカウントへ付与します。
5. 購入完了画面とアカウント画面でポイントを確認できます。

## 必須設定

- `supabase/purchase-points-migration.sql` をSupabase SQL Editorで実行
- `.env.local` に `SUPABASE_SERVICE_ROLE_KEY` を追加

Service Role keyはNext.jsサーバー内だけで利用し、ブラウザへ公開しません。

## セキュリティ

- 商品価格、送料、ポイントはNext.jsサーバーで再計算します。
- Supabaseのアクセストークンで購入者本人を確認します。
- 注文IDによる冪等性を持たせ、同じ購入処理の再送による二重ポイント付与を防ぎます。

## 現在の範囲

これはデモ用の購入確定機能です。クレジットカード、コンビニ払い、配送APIなどの実決済・実配送連携は含みません。
