# 自作ロボット保存・アカウントアイコンの追加手順

## 既存のSupabaseプロジェクトへ追加する場合

1. Supabase Dashboardを開きます。
2. **SQL Editor** を開きます。
3. このプロジェクトの `supabase/robot-storage-migration.sql` を開き、中身をすべて貼り付けて実行します。
4. サイトを再読み込みします。

既存の `profiles`、`favorites`、アカウント情報は削除されません。

## 動作確認

1. ログインします。
2. 「ロボット工房」でロボットを作ります。
3. 「このロボットを保存」を押します。
4. 「アカウント」で保存したロボットが表示されることを確認します。
5. 「アイコンにする」を押します。
6. ヘッダーとマイページのアイコンが変わることを確認します。
7. 「工房で編集」から読み込み、変更を上書き保存できることを確認します。

## 保存される内容

- ボルタ／ナッティの種類
- 名前
- 大きさ
- ボディ色・アクセント色
- ポーズ
- 持ち物
- 表示方向
- アカウントアイコンに選ばれているか

パスワードやメールアドレスは `saved_robots` テーブルには保存されません。
