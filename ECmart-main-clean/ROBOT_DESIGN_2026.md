# ボルタ／ナッティ デザイン更新

今回の更新では、ECサイトの既存機能と保存形式を維持したまま、2D SVG と 3D React Three Fiber の形状を同じ設計へそろえました。

## 共通形状

- 六角ボルト頭を側面から見た、幅を抑えた頭部
- 六角頭の上に載る2本のプラス皿ねじの目
- 小さな丸ジョイントで接続する腕
- 細い曲げ棒の腕と、皿ねじ頭の手先
- 長いねじ軸の胴体
- 棒状の脚と、皿ねじ頭を側面から見た足先

## キャラクター差分

- ボルタ: ねじ軸から脚へ直接つながる細身形状
- ナッティ: ねじ軸の下に大きな皿ねじ頭のスカートを追加

## 互換性

Supabaseへ保存する `base / pose / item / view / size / bodyColor / accentColor` は変更していません。既存の保存済みロボットにも新しい2D／3D形状が適用されます。
