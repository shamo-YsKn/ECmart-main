# ロボット 2D / 3D 表示構成

## 基本方針

- 2D表示を正式な表示として使用します。
- ホーム、アカウントアイコン、保存ロボット一覧、スマホ/タブレットの工房は常に2Dです。
- PCのロボット工房だけ、2D / 3D 切り替えボタンを表示します。
- 3Dはユーザーが3Dボタンを押したときだけ遅延読み込みされます。
- 3D表示モードそのものはSupabaseへ保存しません。

## 2D / 3D パーツの紐づけ

`lib/robot-parts.ts` が共通パーツレジストリです。

Supabaseに保存されている既存キー：

- `base`: `volta` / `natty`
- `pose`: `stand` / `wave` / `cheer` / `point`
- `item`: `none` / `wrench` / `gear` / `flower` / `heart`
- `view`: `front` / `side` / `back`

これらのキーから、同じレジストリ内の `twoD` と `threeD` の定義を参照します。
そのため保存形式を変えずに、同じロボットを2D / 3Dで表示できます。

将来SVGパーツやGLBモデルへ差し替える場合も、保存キーを維持したままレジストリ側の表現だけを変更してください。
