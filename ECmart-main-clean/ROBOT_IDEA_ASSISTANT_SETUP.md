# ⑤-1〜⑤-5 イメージ提案・自作アイテム連携 実装メモ

更新日: 2026-10-01

## 概要

外部AI APIを使わず、文章からボルタ／ナッティの構成候補と、自作アイテムの工作パーツ構成を提案する版。

処理フロー:

1. 作りたいイメージを文章入力
2. `lib/robot-idea-engine.ts` がタイプ・テーマ・向き・ポーズ・色・既存持ち物を解析
3. 3候補を既存 `RobotConfig` として生成
4. 自作アイテムが必要な候補では `lib/custom-item-idea-engine.ts` が工作テンプレートを生成
5. 生成した `CustomItemDocument` を既存の価格スコアで評価し、工作Tier込みの参考価格を表示
6. 「工作台へ読み込む」で `sessionStorage` を介して既存工作台へ渡す
7. 工作台でユーザーが自由に修正・保存し、通常どおりロボットへ装備できる

## ⑤-1〜⑤-4

- PC / スマホで文章から3案を提案
- 約25テーマをルールベース認識
- 明示されたボルタ／ナッティ、向き、ポーズ、色を優先
- ガチャ未解放の既存持ち物や色は強制使用しない
- 候補は必ず既存 `RobotConfig` へ正規化
- 校正済み価格モデルを候補カードに表示

## ⑤-5 自作アイテム工作案

外部APIなしの純粋なルールベース生成。

現在の主なテンプレート:

- 釣竿
- ギター
- クラリネット
- 室蘭やきとり串
- バイク
- カメラ
- 本・資料
- 魔法の杖
- スキー
- 筆
- トレーとカップ
- 望遠鏡
- 刀・剣
- 槍
- フライパン
- プレゼント箱
- 汎用スポーツ用具

生成には現在工作台で実在する部品型だけを使う。
ガチャ限定 `variantId` は自動提案で使用しないため、未解放素材を勝手に生成しない。

対応できない未知の物体名では `null` を返し、存在しない部品や工作データを捏造しない。

### 工作台への受け渡し

PC版の候補カードに「工作台へ読み込む」を追加。

使用キー:

- `machinowa:custom-item-draft`: 生成した `CustomItemDocument`
- `machinowa:robot-draft`: 元の候補 `RobotConfig`

両方とも `sessionStorage` のため外部送信しない。
工作台からロボット工房へ戻ったとき、元の候補ロボットを復元できる。

工作台は既存保存フローをそのまま利用するため、正式保存・ロボット装備には従来どおりログインが必要。
ゲストでも生成案を工作台で確認・編集できるが、アカウント保存は行わない。

### 価格連携

工作案は生成直後に `estimateCustomItemPrice()` へ渡す。

代表例:

- 釣竿: 通常範囲
- ギター: 詳細小物
- クラリネット: 詳細小物
- 室蘭やきとり串: 高複雑度
- バイク: 大型・機械構造

候補カードの参考価格は、キャラクター基本価格 + 生成工作のTier加算として表示する。

## スマホ互換表示

スマホにも工作案の名前・パーツ数・Tier・加算額を表示する。
自由ドラッグ工作台自体が従来PC版限定のため、スマホでは「PC版で自動読み込み可能」と案内する。

## AI接続 ON/OFF

現段階では外部AI APIを使用しない。

- OFF: ルールベース
- ON: 設定値は保存するが、接続先未設定のためルールベースへフォールバック

`lib/robot-idea-engine.ts` と `lib/custom-item-idea-engine.ts` に `fetch()` や外部API URLはない。
したがって⑤-5までの利用でAPI料金は発生しない。

将来⑤-6で外部AIを追加する場合も、AIの出力を直接工作台へ入れず、現在の `RobotIdeaCandidate` / `CustomItemDocument` 形式へ検証・正規化してから使用する。
無料枠のあるAPIを利用する場合も、このルールベース経路を常時フォールバックとして残す。

## DB / SQL

追加SQL不要。既存 `saved_custom_items` のJSON保存形式をそのまま使う。

## 検証

- `npm run validate:idea-assistant`
- `npm run validate:item-idea-assistant`

⑤-5専用validatorでは以下を確認する。

- 代表8入力が意図したテンプレート・価格Tierになる
- 不明入力では工作データを捏造しない
- 外部通信コードを持たない
- RobotIdea候補へ工作案が接続される
- PC版で `sessionStorage` を介して工作台へ渡す
- 工作台がAI提案ソースを認識する
- スマホではPC工作台限定であることを明示する
