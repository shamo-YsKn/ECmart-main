# 左側面・右側面の追加（2026-09-24）

腕動作の再調整は行わず、ロードマップ②の左右側面を追加しました。フェーズ6の機能を含む更新版です。

## 向きの基準

左右はロボット自身を基準にしています。

| 画面の選択肢 | 保存値 | 表示 |
| --- | --- | --- |
| 正面 | `front` | 従来どおり |
| 左側面 | `side` | 従来の側面。顔は画面の左向き |
| 右側面 | `side-right` | 追加した反対側。顔は画面の右向き |
| 背面 | `back` | 従来どおり |

既存の `side` の意味・見た目を保持しています。保存済みロボットやジオラマを一括変換する必要はありません。

## 使える場所

- ロボット工房：向きのボタンから4方向を選択。既存の3D表示も左右の回転方向に対応。
- 自由ポーズ：側面パネル上部の「左側面」「右側面」で切り替え。工房で選んだ向きを保ったまま専用画面へ移動できます。
- ジオラマ：配置したロボットを選び、向きを変更。保存・再編集・公開ギャラリーでも維持。
- 壁画：投稿時の向きから選択。公開表示とスマホの壁画閲覧にも反映。
- スマホ互換工房：向きの選択・表示・保存に対応。自由ドラッグ編集の提供範囲は従来どおりPC版中心。

右側面では、顔や体を反対向きにし、腕・脚の手前／奥を入れ替えます。持ち物は同じ手に付いたまま、体との重なり順が変わります。

両側面は同じYZポーズデータを共有します。切り替えただけでは関節角やXYZを変更しません。右側面の操作座標は保存前に共通座標へ戻すため、X保持・Z共有の既存ルールを維持します。投影が一点になる場合の操作距離も同じ座標系で計算します。

自作アイテム自体の正面・側面・背面制作は、次の③の作業です。今回の持ち物は既存2D図形を左右の表示に追従させるもので、アイテムの奥行き形状を新たに生成するものではありません。

## 導入手順

1. 現在のコードをバックアップし、更新版へ切り替えます。既存の `.env.local` は引き継いでください。
2. フェーズ6まで設定済みのSupabase SQL Editorで、`supabase/robot-side-views-migration.sql` を実行します。
3. `npm ci` → `npm run check` → `npm run build` → `npm run dev` の順に実行します。

追加SQLは壁画の `robot_view` の制約へ `side-right` を追加するだけです。既存投稿・ロボット・公開権限を変更せず、再実行できます。未実行でもローカルの表示は使えますが、右側面での壁画投稿は保存できません。

新規環境ではフェーズ5・6までの設定を先に行い、このSQLを最後に実行してください。以前の壁画SQLを後から再実行した場合も、このSQLを最後に再実行してください。Phase 6の公開権限を戻さないよう、`PHASE_6_SETUP.md` のSQL順序にも従ってください。

公開済みジオラマは従来のスナップショット方式のままです。向きの変更をギャラリーへ反映する場合は、ジオラマを保存した後に「公開内容を更新する」を押してください。
