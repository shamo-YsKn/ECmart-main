# XZ / YZ pose sync

自由ポーズの正面・側面同期を、2つの直交平面として整理しました。

- 正面: XZ平面
  - X = 左右
  - Z = 高さ
- 側面: YZ平面
  - Y = 前後
  - Z = 高さ

## 同期ルール
- 正面で編集: X と Z を更新し、Y は保持
- 側面で編集: Y と Z を更新し、X は保持
- 正面と側面で共有するのは Z のみ

`RobotPoseState.spatial` に各腕・脚区間の `{x, y, z}` をoptionalで保存します。
旧保存データでは spatial が存在しなくても従来角度データからそのまま表示できます。

## 検証
- spatial未使用時の旧版とのレイアウト差: 0
- front投影: (x, -z)
- side投影: (y, -z)
- front編集後もY保持を確認
- side編集後もX保持を確認
